Menggunakan React Native + Expo.
Karena tidak bisa push semua file dikarenakan .env yang sensitif. Saya akan memberikan langkah-langkah untuk menjalankan appsnya.
1. Jalankan di cli npx create-expo-app@latest --template blank ./
2. copy semua file yang ada di repo ini kedalam root project
3. jalankan dengan "npx expo start"
4. Jalankan backend dengan menginstall requirement.txt terlebih dahulu dengan "pip install -r requirement.txt"
5. Kemudian "python app.py"
6. Untuk setting .env menggunakan api OpenAI & Twitter.
